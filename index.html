隱私權政策

應用程式：shopee-threads-bot（Meta / Threads API）　最近更新：2026-07-14

本隱私權政策說明 shopee-threads-bot（一個透過 Meta Threads API 自動於公開 Threads 帳號發文之應用程式，以下簡稱「本應用」）如何處理使用者資料。

1. 我們收集什麼

  • 透過 Meta 授權（OAuth）取得的：Threads 帳號 ID、使用者名稱（username）。
  • 為完成發文功能所處理的內容：發帖文字、圖片、蝦皮聯盟連結。
  • 不會收集或保存您的密碼、金流或其他與發文無關的個人資訊。

2. 用途

  • 僅用於以您的 Threads 帳號發布內容（蝦皮分潤商品的貼文與連結）。
  • 資料僅在執行發文流程時暫時處理，非必要不移轉或長期留存。

3. 資料共享

  • 不販賣、不出售任何個人資料。
  • 發文內容會依 Threads 平台規範公開顯示；蝦皮聯盟連結導向蝦皮平台。

4. 您的權利

  • 您可隨時在 Meta 帳號設定中移除本應用的存取權限，或刪除已發布的貼文。
  • 如需查詢、修正或刪除資料，請洽 contact 信箱（見下方）。

5. 聯絡方式

若對本政策或資料處理有任何問題，請致電或來信：loveyun996@gmail.com

本政策可能更新；如有重大變動將以同一頁面更新為準。
